Paràbola i recta

Objectiu

Defineix la funció f(x) = x² i la recta g(x) = x + 2. Marca els dos punts on es tallen les dues gràfiques.

Widget

Construeix la solució i prem ✓ Comprova quan acabis.

💡 Pista

Escriu f(x) = x^2 a la barra d'entrada (després de l'exponent, prem la tecla → per sortir-ne) i després g(x) = x + 2. Amb l'eina «Intersecció» de la pestanya «Eines», fes clic a les dues gràfiques, o escriu Intersecció(f, g). Amb àlgebra: x² = x + 2 → x² − x − 2 = 0 → (x − 2)(x + 1) = 0. Els punts són (2, 4) i (−1, 1).
