Sinus i cosinus

Objectiu

Defineix les funcions f(x) = sin(x) i g(x) = cos(x). Marca dos punts on es tallen les gràfiques i mesura l'angle amb què es tallen en un d'ells (l'angle entre les dues rectes tangents).

Widget

Construeix la solució i prem ✓ Comprova quan acabis.

💡 Pista

Escriu f(x) = sin(x) i g(x) = cos(x) a la barra d'entrada. Les gràfiques es tallen quan sin(x) = cos(x): a x = π/4 ≈ 0.785 i a x = 5π/4 ≈ 3.927. Marca aquests punts amb «Intersecció» o escrivint P=Intersecció(f, g, 0, 2) i Q=Intersecció(f, g, 3, 5) (busca el tall entre x = 0 i x = 2, i entre 3 i 5). En un d'ells, traça la tangent a cada corba amb l'eina «Tangents» (a=Tangent(P, f) i b=Tangent(P, g)) i mesura l'angle entre les dues rectes amb l'eina «Angle» (Angle(a, b)). Segons l'ordre dels clics, GeoGebra mostrarà 70.53°, 109.47°, 250.53° o 289.47°: totes quatre mesures corresponen al mateix angle entre les dues rectes, 70.53°.
